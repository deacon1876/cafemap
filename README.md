# 삼성본관 도보권 휴게음식점 지도

서울 열린데이터광장의 **"서울시 중구 휴게음식점 인허가 정보"** 공공데이터를 기반으로,
삼성본관 도보 10분 이내 영업중인 휴게음식점 **373곳**을 전수 반영했습니다. 배경 컬러 팔레트는 로즈골드 핑크 톤입니다.

- 기준점: 삼성본관 (서울 중구 세종대로 67, 태평로2가 250)
- 기술 스택: HTML / CSS / JavaScript / 카카오맵 API
- 데이터 출처: 서울 열린데이터광장 "서울시 중구 휴게음식점 인허가 정보" CSV (사용자 제공, 2026.08.06 기준)
- 데이터 처리: EPSG:5174 → WGS84 좌표변환, 영업상태 "영업/정상"만 필터, 삼성본관 기준 Haversine 직선거리 + 도보 감쇠계수(1.25) 적용해 도보 10분(약 700m) 이내로 컷오프, 이름+주소 중복 제거
- 필터: **업태**(커피숍/다방/기타휴게음식점/과자점/아이스크림/전통찻집/패스트푸드/편의점/백화점/일반조리판매/푸드트럭) + **브랜드**(스타벅스/투썸플레이스/커피빈/CU/GS25/독립 등 25종) + 도보거리, 3개 축을 독립적으로 조합 가능

```
cafe-map/

│   └── app.js            # 검색 / 업태·브랜드·도보거리 필터 / 리스트 렌더링

```

## 실행 전 꼭 해야 할 일 — 카카오맵 키 발급

1. https://developers.kakao.com 에서 애플리케이션 생성
2. **JavaScript 키**(REST API 키 아님) 복사
3. `index.html` 하단의 다음 줄에서 `appkey=` 값을 교체
4. 카카오 개발자 콘솔 → **내 애플리케이션 → 앱 설정 → 플랫폼 → Web**에 사용 중인 도메인 등록
   - 로컬 테스트: `http://localhost:5500`
   - 배포 시: `https://<github-id>.github.io`
